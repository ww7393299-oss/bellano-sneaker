## 🚀 How to Use Downloaded Files

### **Step 1: Download the Folder**
- Download the entire `bellano-website` folder to your computer

### **Step 2: Open Terminal/Command Prompt**
```bash
cd path/to/bellano-website
```

### **Step 3: Install Dependencies** (MUST DO)
```bash
npm install
```
This downloads all required packages (React, Tailwind, Vite, etc.)

### **Step 4: Start Development Server**
```bash
npm run dev
```

### **Step 5: Open in Browser**
Visit: `http://localhost:5173`

## 🎨 Customize Your Website

### **Change Brand Name**
Edit `Navbar.jsx`:
```jsx
<h1>YOUR BRAND NAME</h1>
```

### **Change Accent Color** (Currently Gold #D4AF37)
Edit `index.css`:
```css
.accent-text {
  color: #YOUR_COLOR;
}
```

### **Add Your Product Images**
Edit product arrays in:
- `Home.jsx`
- `Shop.jsx`
- `ProductDetails.jsx`

### **Update Company Info**
Edit `About.jsx` with your story, team, mission
